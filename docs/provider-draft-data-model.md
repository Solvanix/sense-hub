# مخطط مسودة المزوّد في SENSE Experience

## حدود النسخة الأولى

هذه النسخة تحفظ **مسودة خاصة لمالكها فقط** من ملف المزوّد. لا تستقبل ملفات، ولا تستدعي نموذج ذكاء اصطناعي، ولا تنشئ ملفًا عامًا، ولا ترسل بيانات إلى المتجر أو Urban‑Sense. الحفظ يقتصر على الحقول النصية المعتمدة من خريطة الاستبانة، وعلى حالتي موافقة منفصلتين.

| المجال | حقول المسودة | التصنيف |
|---|---|---|
| ملكية المسودة | `ownerId`، و`id`، وحالة المسودة وتواريخ الإنشاء والتحديث | خاص جدًا |
| الموافقات | موافقة معالجة المسودة، وموافقة مستقلة محتملة على قائمة عامة | خاص جدًا |
| تعريف الخدمة | اسم العلامة، القطاع، فئات الخدمات، المنطقة العامة، وصف خاص، مسودة وصف عام | خاص ثم عام بعد مراجعة |
| تجربة الضيف | اللغات، مسار/رابط الحجز، الموسمية | خاص ثم عام بعد موافقة |
| التشخيص | أولويات النمو والعوائق | خاص فقط |
| الادعاءات | الاستدامة أو العضوية بصفتها «ذكرها المزوّد» | خاص حتى وجود دليل وحالة تحقق منفصلة |

## حالة المسودة

يقتصر حقل `status` على `draft` في هذه النسخة. ولا توجد عملية تحول إلى `submitted` أو `published`. عند إضافة المراجعين وسياسة الاحتفاظ لاحقًا، سيصبح الانتقال المقترح: `draft` → `submitted` → `under_review` → `approved_for_publication`، مع سجل تدقيق لكل انتقال.

## حد الإسقاط العام

لا تستدعي بوابة المسودة دالة `projectPublicProviderProfile` تلقائيًا. تلك الدالة تظل طبقة حماية مستقلة: لا تعطي ناتجًا إلا عند موافقة نشر وموافقة مراجع، ولا تنسخ الاتصال أو الأداء أو العوائق أو الملفات أو الإحداثيات الدقيقة.
